Mini Projects: Tic-Tac-Toe & Pac-Man

September 11, 2025

I have decided that by July of next year, I will have finished two major personal projects: my own Chess engine and my own Clash Royale engine. But before I start working on these very ambitious projects, I shall start with something much more simple.

Mini Project 1:

An unbeatable Tic-Tac-Toe game AI with a beautiful web UI to actually play against it. This was one of the programming assignments for CSE-30 (Programming Abstractions: Python), an intro Python programming class I took at UCSC. Back then, I didn’t fully understand the minimax algorithm (which is the key algorithm behind making this game AI).

This time around I would also want to implement a few more optimizations like alpha-beta pruning, and then finally try to train a neural network for this task (which is probably overkill for such a simple game, but I’m doing this to develop an understanding so that I can apply it to much harder games like Chess and Clash Royale).

I will also go one step further and build the same game AI for Ultimate Tic-Tac-Toe.

Mini Project 2:

Next, I want to build a game AI for the Pac-Man game. This was one of the main focuses of CSE-140 (Artificial Intelligence), an upper-division class I took at UCSC. I never really went all in on the assignments to understand them in detail, I just did enough to get them done, nothing more. I am not too sure of the details of how I shall go about this. What algorithms? A neural net? Etc. I will figure out the details as I go along.

My tentative timeline is to spend about a month on each mini-project.
